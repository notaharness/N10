---
title: Babysit a pull request
description: Keep an agent told about failing checks, new review comments and conflicts.
---

Right-click a pull request in the sidebar and choose
**Babysit pull request**. From then on, n10 tells the pull request's agent
when CI fails, when reviewers leave comments and when the branch conflicts.
It collects the updates and sends them together, once the agent is idle, so
it isn't interrupted mid-task.

Choose **Stop babysitting** from the same menu to turn it off.
