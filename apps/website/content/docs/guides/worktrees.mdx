---
title: Work on several branches at once
description: Each branch gets its own Git worktree and agent session.
---

Each branch you work on in n10 gets its own Git worktree and agent session.
Switch between them from the sidebar. There's nothing to stash, and your
main checkout is left alone.

- **New branch**: press `⌘N` (`Ctrl+N` on Linux and Windows), type the branch name and choose
  **Create branch … and open a worktree**.
- **Existing branch or pull request**: find it in the command palette under
  **Check out branch**, or right-click its row in the sidebar and choose
  **Check out as worktree**.

## What the sidebar shows

Each worktree's row shows its pull request, CI checks, review status and
conflicts. The status turns red when a check fails or a reviewer asks
for changes, and solid green when checks pass and every reviewer approves.

## Keeping worktrees current

n10 checks each worktree for conflicts with the base branch and notices when
its pull request is merged. In [Settings](/docs/configuration), **Auto
Rebase** keeps worktree branches rebased onto the base branch, and **Auto
Delete on Merge** removes a worktree once its pull request is merged. In the
terminal UI, `u` rebases the selected worktree.

To remove a worktree yourself, right-click it and choose
**Remove worktree…**.
