---
title: Version control providers
description: GitHub and Azure DevOps support and test coverage.
---

| Provider     | Authentication         | Test coverage                                        |
| ------------ | ----------------------- | ----------------------------------------------------- |
| GitHub       | Authenticated `gh` CLI | Unit, offline end-to-end, and live integration       |
| Azure DevOps | Personal access token  | Unit tests and recorded API responses; no live tests |

GitLab, Bitbucket, and other providers are not currently supported.

Azure DevOps tests use recorded responses, so CI may miss changes to the
live service. Bug reports help us catch those gaps.

Providers share an interface in `libs/vcs/`. Contributions adding support
for other providers are welcome.

## Pair with Orchestra

[Orchestra](/docs/orchestra) lets your agent launch and coordinate other
agents in worktree sessions, which you can follow in n10 next to your own.
Reports from Orchestra players on other machines reach n10 Desktop over
[Beam](/docs/beam), and n10 Desktop hands them to the orchestrator. The
[Orchestra page](/orchestra) has an overview.
